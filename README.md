# 情報セキュリティ学術研究マップ ＜ISAM＞ (Information Security Academic research Map)

情報セキュリティの世界で、主に日本の研究者がどのような研究を行ってきたかを網羅的に検索できるサービスです。  
オリジナルである 2010 年の [@akirakanaoka et al.](https://4403.biz/ISAM/about.php) の精神を受け継ぎ、サーバーレスで動作するモダンかつ極めて高速な**超軽量・高性能全文検索Webアプリケーション**として GitHub Pages 向けに再構築されました。

---

## 🔍 ISAM について

情報セキュリティ学術研究マップ（Information Security Academic research Map: ISAM）は、日本の主要な情報セキュリティ系シンポジウムのプログラム情報を集約・データベース化し、学術的な研究動向や著者・所属のマップ化をサポートする検索プラットフォームです。

分野の判定については、各シンポジウムで設定された臨場感あるセッション名（例：`電子商取引/超流通`、`暗号ツール規制` など）をベースにしており、当時の研究トレンドをそのまま感じることができます。

## 📊 収録データセット（大幅アップデート版）

オリジナルのシステム（SCIS2001〜2010、CSS1999〜2010）からデータが大幅に更新され、過去四半世紀にわたる日本の情報セキュリティ研究の歴史をほぼすべて網羅する超大規模データベースへと進化しました。

*   **暗号と情報セキュリティシンポジウム (SCIS)**
    *   **収録範囲**: 2001年 〜 2026年 (SCIS2026 までの全26年分)
*   **コンピュータセキュリティシンポジウム (CSS)**
    *   **収録範囲**: 1999年 〜 2025年 (CSS2025 までの全26イベント分 ※2005年除く)
*   **総論文インデックス件数**: **`12,929` 件** のメガ統合データベース

## 🚀 主な機能 (Features)

1.  **超高速の瞬時全文検索 (Fast Client-side Search)**
    *   サーバーとの無駄な通信を行わず、クライアントサイド（JavaScript）で完結する高速ローカルインデックス検索を採用。キー入力をした瞬間に数万件の候補からマッチする論文を絞り込みます。
2.  **制約の撤廃と無限スクロール (No 30-items Limit & Infinite Scroll)**
    *   かつての「検索結果は上位30件まで」という制限は**完全に撤廃**されました。Lazy Load（遅延レンダリング）技術により、どれほど大量のヒット件数でもブラウザの動作を重くすることなく、スクロールするだけで全件を滑らかに閲覧可能です。
3.  **スマートなスペース区切りマルチキーワード検索**
    *   スペース区切りで「著者名 所属」「タイトル キーワード」などを入力することで、高度な AND 条件による絞り込み検索が直感的に行えます。
4.  **クリッカブル所属フィルタ (Clickable Affiliations)**
    *   検索結果カードに表示されている著者所属（例：`情報セキュリティ大学院大学`、`NTT`、`静岡大`など）をクリックするだけで、同一組織に所属する著者の論文を瞬時にワンクリック検索できます。
5.  **学会・年度別マルチセレクト動的フィルター**
    *   「CSS」「SCIS」の学会ごとに、年度単位で細かくチェックボックスによる絞り込みが可能です。全選択・全解除もワンクリックで操作できます。
6.  **発表年ソート機能**
    *   「新しい順（降順）」と「古い順（昇順）」の切り替えに完全対応。最古である 1999 年の日本のセキュリティ研究の黎明期から最新の 2026 年の研究まで、時系列で研究の変遷を追うことができます。
7.  **公式プログラムへの動的リンク**
    *   検索結果に表示される学会バッジをクリックすると、各年度の公式プログラム詳細ページへ直接ジャンプ可能です（SCISや超過去CSSの独自ルーティング・外部サーバーリンクにも自動で対応）。

## 🛠️ 使い方 (How to Use)

1.  検索窓（`論文名、著者名、所属、セッション名など...`）に、探したいキーワードを入力します。
2.  「登壇発表のみ」や「企画セッションのみ」をトグルスイッチで切り替えることで、特別講演や座長情報などの絞り込みも容易に行えます。
3.  ソートボタンで「新しい順」「古い順」を切り替えて、目的に合った順序で閲覧します。

## 💻 ローカルでの開発・カスタマイズ

本プロジェクトは、モダンな Python 開発環境である `uv` (Astral) を用いて、データのクローリング・クレンジングおよびパースのパイプラインが構築されています。

### 1. 依存ライブラリのセットアップ
```bash
# uv を用いた環境構築
uv sync
```

### 2. ローカル開発サーバーの起動
Webアプリは完全に静的な HTML/JS/CSS で構築されているため、任意のシンプルな HTTP サーバーで起動可能です。
```bash
# Pythonの標準モジュールを使用した起動 (ポート 8000)
python -m http.server 8000
```
ブラウザで [http://localhost:8000/](http://localhost:8000/) を開いて開発を行います。

### 3. プログラムデータの再生成・クローリング
プログラム HTML から JSON データを生成・更新する場合は、`scripts/parser.py` を使用します。
```bash
# 特定のイベントのパースを実行 (例: CSS2025)
uv run scripts/parser.py --event CSS2025 --url https://www.iwsec.org/css/2025/program.html --output data/css2025.json
```
